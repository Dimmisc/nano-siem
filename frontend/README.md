# Nano-SIEM

React + TypeScript + Vite. Отдельная панель SOC, не сайт-мишень.

```bash
npm install
npm run dev
npm run build
```

Вкладки: панель мониторинга, события, предупреждения. Поиск, фильтры и детали используют демонстрационные данные. Суммарная статистика на главной относится к демонабору за сутки; список событий показывает только 10 примеров. API чтения не согласован: локальные модели не являются контрактом бэкенда. Не подключать интерфейс к endpoint приёма логов агента.

Дизайн основан на ранее полученном макете Figma и HTML-демо. Точное соответствие всех экранов, сборка и проверка в браузере требуют отдельной проверки. Docker и интеграция с сервером не включены в этот стартовый пакет.
